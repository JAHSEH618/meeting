# P2.1: Lease Model Rework Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rework the processing task lease model so tasks are created QUEUED without pre-claiming a lease, the worker's first callback claims it, heartbeats renew for 120s, and expired leases in WORKER_DAG_RUNNING phase trigger requeue with attempt increment.

**Architecture:** The current model pre-claims leases at task creation with a hardcoded `worker_dev_001` owner. The new model: (1) tasks start QUEUED with null lease, (2) first worker callback via `claimLease()` transitions QUEUED→RUNNING and sets lease, (3) heartbeats renew lease +120s from now, (4) `ProcessingTaskLeaseScanner` only scans phase=WORKER_DAG_RUNNING, (5) expired → ORPHANED → `requeueOrphaned()` increments attempt and resets to QUEUED, (6) `completeWorkerPhase` clears the lease, (7) callback path uses row-level locking (`SELECT FOR UPDATE`).

**Tech Stack:** Java 17, Spring Boot 3.3, MyBatis-Plus, PostgreSQL, Flyway

**Branch:** fix/review-remediation-p2-meeting-api
