### 2. Real Model Infrastructure (9 tasks)

**Model Checksum Utility**:
- `ai_worker/observability/model_checksum.py` computes SHA-256 of model weights
- Supports `.safetensors`, `.bin`, `.pt`, `.pth`, `.gguf`, `.onnx`

**ModelLoader**:
- `ai_worker/model_runtime/loader.py` with checksum verification
- Loads from `/opt/models/` with optional integrity checks

**Five Model Runtimes** (all with fake/real toggle):
1. **Qwen3AsrRuntime** (256 lines) - Speech recognition with FunASR
2. **PyannoteDiarizationRuntime** (204 lines) - Speaker diarization
3. **Cam++SpeakerRuntime** (184 lines) - Speaker embeddings (NEW)
4. **BgeM3EmbeddingRuntime** (215 lines) - Text embeddings
5. **BgeRerankerRuntime** (170 lines) - Reranking

All runtimes follow the same pattern:
- Fake mode: deterministic output for tests/CI
- Real mode: lazy-load models only when `ensure_loaded()` is called
- State machine: `NOT_LOADED → LOADING → READY / ERROR`
- GPU concurrency via device semaphore
- Offline mode enforced (no HuggingFace downloads in prod)

## Deployment Requirements

### Model Staging

Models must be staged under `/opt/models/`:

```
/opt/models/
├── qwen3-asr/v1/           # ~8GB VRAM
├── pyannote/v3.3/          # ~2GB VRAM  
├── cam++/v1/               # ~1.5GB VRAM
├── bge-m3/v1/              # ~2GB VRAM
└── bge-reranker-v2-m3/v1/  # ~1GB VRAM

Total: ~14.5GB + 4GB inference buffer = 19GB
RTX 4090 (24GB) recommended
```

### Environment Variables

**ai-worker**:
```bash
# Model directories
AI_WORKER_QWEN3_ASR_MODELS_DIR=/opt/models/qwen3-asr/v1
AI_WORKER_PYANNOTE_MODELS_DIR=/opt/models/pyannote/v3.3
AI_WORKER_CAM_PLUS_PLUS_MODELS_DIR=/opt/models/cam++/v1
AI_WORKER_BGE_M3_MODELS_DIR=/opt/models/bge-m3/v1
AI_WORKER_BGE_RERANKER_MODELS_DIR=/opt/models/bge-reranker-v2-m3/v1

# Offline mode (prevent HuggingFace downloads)
HF_HUB_OFFLINE=1
TRANSFORMERS_OFFLINE=1

# Use real models (default: fake for dev)
AI_WORKER_USE_FAKE_RUNTIME=false
AI_WORKER_USE_FAKE_ASR_RUNTIME=false
AI_WORKER_USE_FAKE_DIARIZATION_RUNTIME=false
```

### Installation

```bash
# Install real model dependencies
cd apps/ai-worker
uv sync --extra real-models

# Or individual extras:
# uv sync --extra real-asr --extra real-diarization --extra real-bge
```
