## 关键决策

### 1. 异步执行器配置
- **决策：** 专用线程池，core=4, max=8
- **理由：** 允许并发处理多个任务，但限制资源使用防止过载

### 2. 事务边界
- **决策：** 每个独立的数据库操作都在自己的事务中
- **理由：** 避免长事务锁定；失败隔离；符合 COLA 边界

### 3. 恢复扫描器间隔
- **决策：** 每分钟扫描一次
- **理由：** 平衡恢复及时性和系统开销

### 4. 事件重新发布
- **决策：** 恢复时重建最小事件（空的 completedSteps/skippedSteps）
- **理由：** ProcessingTask 不存储这些信息；监听器会重新读取任务状态
